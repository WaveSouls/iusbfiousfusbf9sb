Возможности

Продукт для команды: быстрый контроль ролей, чистая аналитика, стабильная обработка заявок и удобное управление без лишних кликов.

Панели управления

  • Админ‑панель: пользователи, воркеры, заявки, рассылки
  • Ворк‑панель: профиль, топ‑лист, заявки, апгрейды

Поддержка выплат

  • Несколько вариантов реквизитов (asset/network/wallet)
  • Ограничения и анти‑спам на заявки
  • Статусы обработки (pending/approved/paid/rejected)

Продуктовая аналитика

  • Live‑активность пользователей по страницам (heartbeat)
  • История действий и аудит

Зеркала ботов

  • Хранение токенов зеркал
  • Запуск/остановка из GUI
  • Корректная настройка WEBAPP_URL

Качество интерфейса

  • Glass-стиль без перегруза
  • Адаптация под телефон и ПК
  • Быстрые действия в один тап
